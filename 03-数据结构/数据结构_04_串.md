## 🔢 计算方法：next 与 nextval（修正 next）数组

> 下标从 0 起。`next[j]` 表示在第 `j` 位失配时，下一步改用模式串哪一位继续和主串当前位比较。

**前缀 / 后缀 / 最长相等前后缀**：

- **前缀**：从串首取连续若干字符；**后缀**：从串尾取连续若干字符。二者都**不含整个串本身**（即只取**真**前后缀）。
- **最长相等前后缀**：既作前缀、又作后缀的**最长**子串，其**长度**就是 next 值。
- 例：`S[0..4] = aabaa` → 前缀 `a, aa, aab, aaba`，后缀 `a, aa, baa, abaa`，公共的只有 `a`、`aa`，最长 = `aa`，长度 **2** = `next[5]`。

**next**：

- `next[0] = -1`，`next[1] = 0`。
- `j ≥ 2`：`next[j]` = 子串 `S[0..j-1]` 的**最长相等前后缀**长度。

**nextval（修正）**：

- `nextval[0] = -1`。
- `j ≥ 1`：若 `S[j] == S[next[j]]`，则 `nextval[j] = nextval[next[j]]`；否则 `nextval[j] = next[j]`。
- **只需查一次表，不现场递归**：按 `j` 从小到大递推，`next[j] < j` ⇒ `nextval[next[j]]` 早已算好，且其自身已含整条 `next` 链的修正；故此处是**取值**而非递归调用。

**失配滑动距离**：第 `j` 位失配时，模式串向右滑动 **`j − nextval[j]`** 位。

**例**（`S = aabaab`，对应错题 [[#1. KMP（nextval）失配时的最长滑动距离]]）：

| j | S[j] | next[j] | S[j] == S[next[j]]？ | nextval[j] | j − nextval[j] |
|---|---|---|---|---|---|
| 0 | a | -1 | — | -1 | 1 |
| 1 | a | 0 | a == a ✓ | nextval[0] = -1 | 2 |
| 2 | b | 1 | b ≠ a | next[2] = 1 | 1 |
| 3 | a | 0 | a == a ✓ | nextval[0] = -1 | 4 |
| 4 | a | 1 | a == a ✓ | nextval[1] = -1 | 5 |
| 5 | b | 2 | b == b ✓ | nextval[2] = 1 | 4 |

得 next = `[-1, 0, 1, 0, 1, 2]`，nextval = `[-1, -1, 1, -1, -1, 1]`；最大滑动距离 = **5**（`j = 4`）。

## ❌ 错题

### 1. KMP（nextval）失配时的最长滑动距离

- **题目**：KMP 算法使用修正后的 next 数组（即 nextval 数组）进行模式匹配，模式串 `S = aabaab`，当主串中某字符与 S 中某字符失配时，S 将向右滑动的最长距离是（ ）。

  - A. 5　← **正确答案**
  - B. 4
  - C. 3
  - D. 2

- **正确答案**：**A**
- **正解过程**：
  1. 求 next（方法见 [[#🔢 计算方法：next 与 nextval（修正 next）数组]]）：`[-1, 0, 1, 0, 1, 2]`（`next[j]` 为 `S[0..j-1]` 的最长相等前后缀长度；如 `j=5` 时子串 `aabaa` 的 `aa` 长为 2）。
  2. 修正求 nextval：`[-1, -1, 1, -1, -1, 1]`（`S[j]==S[next[j]]` 时取 `nextval[next[j]]`，否则取 `next[j]`）。
  3. 逐位求滑动距离 `j − nextval[j]`：`1, 2, 1, 4, 5, 4`。
  4. 最大为 **5**（`j = 4`），选 **A**。
