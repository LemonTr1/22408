# 05 树与二叉树

> 重点：遍历、线索二叉树、哈夫曼树、并查集

## ⚠️ 易错点 / 难点

- **森林/树 → 二叉树：遍历对应关系**（用「左孩子 = 第一个孩子，右孩子 = 下一个兄弟」转换后）：
  - **森林的先根遍历 ⇄ 二叉树的先序遍历**
  - **森林的后根遍历 ⇄ 二叉树的中序遍历**
- **最易错记成「后根 ⇄ 后序」**：森林/树**没有**「中序遍历」，二叉树上做中序遍历时等价的是森林的**后根遍历**，不是后序遍历。
- **树的结论与森林一致**：树的先根遍历 ⇄ 二叉树先序；树的后根遍历 ⇄ 二叉树中序。
- **非空二叉树：叶子结点数 = 度为 2 的结点数 + 1**，即 **`n₀ = n₂ + 1`**（记 `n₀/n₁/n₂` = 度 0/1/2 的结点数）。
  - **推导一（边数法）**：设结点总数 `n = n₀ + n₁ + n₂`。非空二叉树中除根外每个结点恰有 1 个父结点，故**边数 = n − 1**；另一方面边数 = 各结点度之和 = `0·n₀ + 1·n₁ + 2·n₂`。
    于是 `n₀ + n₁ + n₂ − 1 = n₁ + 2n₂` → 两边消去 `n₁` 得 **`n₀ = n₂ + 1`**。
  - **推导二（孩子数法）**：结点总数 = 根结点 + 所有孩子结点数 = `1 + (n₁ + 2n₂)`，即 `n₀ + n₁ + n₂ = 1 + n₁ + 2n₂` → 同样得 **`n₀ = n₂ + 1`**。
  - **配套变形（常考）**：`n = n₀ + n₁ + n₂ = 2n₀ + n₁ − 1 = 2n₂ + n₁ + 1`。
  - **⚠️ 易错三点**：① 结论与 `n₁` **无关**，对任何非空二叉树恒成立；② 必须 `n ≥ 1`，**空树不成立**（空树 `n₀ = n₂ = 0`，`0 ≠ 1`）；③ 只知道 `n₀ = n₂ + 1` 无法定 `n₁`，需额外条件——**满二叉树** `n₁ = 0`；**完全二叉树**中 `n₁` 只能是 0 或 1（`n` 为奇数 → `n₁ = 0`，`n` 为偶数 → `n₁ = 1`），进而 `n₀ = ⌈n/2⌉`。

- **二叉树空指针域（链式存储，`n` 个结点共 `2n` 个指针域）**：

  **✅ 一、无条件结论（任何非空二叉树都成立，必背）**

  **空指针域总数 = `n + 1`**

  - **推导（一句话）**：`2n` 个指针域中，**非空的每一个都对应一条边**（父亲 → 孩子），而非空二叉树恰好有 `n − 1` 条边。故 **空域数 = `2n − (n − 1)` = `n + 1`**。
  - **记忆**：`2n` 个座位，只坐了 `n − 1` 个孩子，剩下 `n + 1` 个空位。
  - **用途**：线索二叉树就是把这 `n + 1` 个空域改存前驱/后继指针（配 `ltag`/`rtag`），从而免去递归栈。

  **⚠️ 二、两个「细分」结论——有前提，不满足前提就是错的**

  - **左空指针数 = 叶子数 `n₀`**
  - **右空指针数 = 非叶结点数 + 1 = `n₁ + n₂ + 1`**
  - **共同前提**：**每个度为 1 的结点都只有左孩子**，即**树里不存在「只有右孩子」的结点**。
    该前提在两种常见情形下**自动满足**：① **完全二叉树**；② **由森林/树按「孩子兄弟表示法」转换得到的二叉树**（有孩子必占左链，有兄弟才占右链）。
  - **满足前提时的推导——「按度分类逐项计数」，这就是那个 `m = n₁ + n₀` 的清楚版本**：

    | 结点类型 | 个数 | 它的左指针 | 它的右指针 |
    |---|---|---|---|
    | 度 0（叶子） | `n₀` | **空** → 贡献 `n₀` 个空左 | **空** → 贡献 `n₀` 个空右 |
    | 度 1（只有左孩子） | `n₁` | 非空 → 贡献 **0** 个空左 | **空** → 贡献 `n₁` 个空右 |
    | 度 2（左右都有） | `n₂` | 非空 → 0 | 非空 → 0 |
    | **合计** | `n` | **`n₀`** | **`n₀ + n₁`** |

    → 「左空 = `n₀`」；「右空 = `n₀ + n₁`」。
    注意 `n₀ + n₁` 正是「**度 ≠ 2 的结点数**」= **非叶结点数**，所以右空 = 非叶 + 1（左式没有 `+1`，右式有，**这是最易记反之处**）。
  - **为什么能写成 `n₁ + n₂ + 1`？** 这只是把 `n₀` 用 `n₀ = n₂ + 1` 换掉后的**等价改写**：
    `右空 = n₀ + n₁ = (n₂ + 1) + n₁ = n₁ + n₂ + 1`。
    **代入只是为了好背，不是第二次计数**——别把它误读成「`n₂` 个结点右孩子非空」那一串啰嗦话。
  - **自洽校验**：`左空 + 右空 = n₀ + (n₁ + n₂ + 1) = n + 1` ✅ 与无条件结论一致。

  **🚨 三、反例：出现「只有右孩子」的度为 1 结点，两个细分结论立刻失效**

  取 2 个结点的右斜二叉树：`A —(右)→ B`（`n₀ = 1, n₁ = 1, n₂ = 0`）

  | 量 | 实际值 | 细分结论声称值 | 结果 |
  |---|---|---|---|
  | 空左指针数 | **2**（A、B 都无左孩子） | `n₀ = 1` | ❌ |
  | 空右指针数 | **1**（仅 B 无右孩子） | 非叶+1 = 2 | ❌ |
  | 空指针域总数 | **3** | `n + 1 = 3` | ✅ |

  → **「左空 = 叶子数」不是普遍真理**，只在「度 1 结点都只有左孩子」的树里成立。

  **四、没有前提时的正确范围（选择题保命用）**

  - **恒等式**：`左空 + 右空 = n + 1`（永远成立，优先用这条）
  - **各自的范围**：`n₀ ≤ 左空 ≤ n₀ + n₁`，`n₀ ≤ 右空 ≤ n₀ + n₁`（右单分支越多，左空越大、右空越小）

- **m 叉哈夫曼树必须先查虚叶**：每次合并 m 个最小结点，净减 m−1 个。**(n−1) mod (m−1) ≠ 0 时补权为 0 的虚叶**，个数 = (m−1) − (n−1) mod (m−1)。虚叶参与构造、**不计入 WPL**。
- **WPL ≠ 根的权值**。WPL = 各次合并产生的**新结点权值之和**（含根）。本题根权 27 是陷阱选项。

## 🧩 易混对比

| A | B | 区别 |
|---|---|---|
| 森林的先根遍历 | 二叉树的先序遍历 | 访问序列**完全相同**（先根 = 先访问根，再依次进入各子树，正好对应先序的「根 → 左 → 右」） |
| 森林的后根遍历 | 二叉树的中序遍历 | 访问序列**完全相同**；**别错记成「对应后序遍历」** |
| 森林的后根遍历 | 二叉树的后序遍历 | **不成立**：后序最后访问的是整棵二叉树的根，而后根遍历最后访问的是**第一棵树的根**，序列不同 |
| 非空二叉树 `n₀` 与 `n₂` | 边数法 / 孩子数法 | 两条路殊途同归，都导出 **`n₀ = n₂ + 1`**：边数法用「边数 = n−1 = Σ度」；孩子数法用「n = 1 + Σ孩子数」。结论与 `n₁` 无关 |
| **空左孩子指针**数 | 叶子结点数 `n₀` | **相等——但有前提**：树中不能有「只有右孩子」的度为 1 结点（完全二叉树、孩子兄弟表示法均满足）。无前提时左空 ∈ `[n₀, n₀+n₁]`，右斜树可使其等于 2 而 `n₀ = 1` |
| **空右孩子指针**数 | 非叶子结点数 + 1 | **同一前提**下相等，= `n₀+n₁` = `n₁+n₂+1`（`n₀ = n₂+1` 代入所得）。**左式不带 +1、右式带 +1，最易记反**；前提被破坏即失效 |
| 空指针域总数 | `n + 1` | **无条件成立**（任何非空二叉树）：`= 2n − (n−1)`，即 `2n` 个指针域减去 `n−1` 条边。线索二叉树正是利用这 `n+1` 个空域 |
| 空指针域**总数** | 左空 / 右空 **各自**的数量 | **别混为一谈**：总数 `n+1` 是铁律；左右的拆分却依赖树的形状（有无右单分支），不能当成两条独立铁律背 |
| 二叉哈夫曼 | m 叉哈夫曼 | 二叉每次合 2 个，(n−1) 必被 1 整除，**永不补虚叶**；m 叉可能要补权 0 的虚叶，否则合不拢 |

## 🔢 计算方法：m 叉哈夫曼树

> 目标：n 个带权叶，构造 m 叉树使 **WPL 最小**。

### ① 要不要补虚叶（公式从哪来）

严格 m 叉哈夫曼树：**每个内部结点恰好 m 个孩子**，没有 1～m−1 度的结点。

**过程视角**：手头有 n 个结点，每次合并拿走 m 个、放回 1 个父结点，**净减 m−1 个**。要从 n 个收到只剩 1 个根，总共必须减掉 n−1 个。所以 **n−1 必须是 (m−1) 的倍数**：

$$n-1 = k(m-1)\quad(k=\text{合并次数})$$

不整除就合不拢——最后会剩下 2,3,…,m−1 个结点，凑不够一次合法合并。

**结点计数视角（同一件事）**：叶 n₀、内部结点 nₘ（全是度 m）。边数 = 总结点数 − 1 = n₀+nₘ−1；边数又 = m·nₘ。故

$$n_0-1=(m-1)\,n_m$$

n₀ 必须 ≡ 1 (mod m−1)。真实叶只有 n 个，差多少就补多少个权 0 的虚叶。

**最少补几个**：余数 r = (n−1) mod (m−1)。r=0 已整除，补 0 个；否则还差 (m−1)−r 才能凑满下一段 (m−1)。虚叶个数 ∈ {0,1,…,m−2}，取最小非负解。

$$(n-1) \bmod (m-1)=0 \;\Rightarrow\; \text{不补};\quad \text{否则补 }(m-1)-(n-1)\bmod(m-1)\text{ 个权为 }0\text{ 的虚叶}$$

本题 m=3，m−1=2，**n−1 必须是偶数**。n=6 → 5 mod 2 = 1 → 补 2−1=**1** 个 0。补完 n₀=7，7−1=6=3×2，合并 3 次刚好收成根。

### ② 构造

把所有叶（含虚叶）放入集合。每次取 **m 个最小**合并成新结点（权=三者之和），新结点放回集合，直到只剩根。

### ③ 算 WPL（两法等价，考场用加法）

- **定义**：Σ（真实叶权 × 根到该叶的路径长度）。虚叶不计入。
- **捷径**：WPL = **每一次合并得到的新结点权值之和**（含最后的根）。

例：叶权 2,3,4,5,6,7，三叉。n=6，(6−1) mod 2 = 1 → 补一个 0。

| 步 | 取最小三个 | 新结点 |
|---|---|---|
| 1 | 0, 2, 3 | 5 |
| 2 | 4, 5, 5 | 14 |
| 3 | 6, 7, 14 | 27 |

WPL = 5+14+27 = **46**（= 6×1 + 7×1 + 4×2 + 5×2 + 2×3 + 3×3）。

## ❌ 错题

### 1. 森林的后序（二叉树）遍历序列（题号 9 · 全国联考 2020 年）

- **题目**：已知森林 F 及与之对应的二叉树 T，若 F 的先根遍历序列是 `a,b,c,d,e,f`，后根遍历序列是 `b,a,d,f,e,c`，则 T 的后序遍历序列是（ ）。

  - A. `b,a,d,f,e,c`
  - B. `b,d,f,e,c,a`
  - C. `b,f,e,d,c,a`　← **正确答案**
  - D. `f,e,d,c,b,a`

- **正确答案**：**C**
- **正解过程**：
  1. **把森林遍历翻译成二叉树遍历**（用易错点区的对应关系）：F 的先根遍历 = T 的**先序**遍历 = `a,b,c,d,e,f`；F 的后根遍历 = T 的**中序**遍历 = `b,a,d,f,e,c`。→ 问题化为：已知先序 + 中序，求后序。
  2. **还原 T**：先序首元素 `a` 为根；在中序中 `a` 把序列切成 左 `{b}`、右 `{d,f,e,c}`。左子树仅 1 个结点 → `b` 是 `a` 的左孩子；`c` 在右子树先序打头、且在中序中处于末尾 → `c` 是 `a` 的右孩子，且**无右孩子**。
  3. **递归展开右子树**：先序 `c,d,e,f`／中序 `d,f,e,c` → 根 `c`；左子树先序 `d,e,f`／中序 `d,f,e` → 根 `d`，`d` 的左子树为空、右子树先序 `e,f`／中序 `f,e` → 根 `e`，`e` 的左孩子为 `f`。
  4. **写出 T 的形状**：`a` 的左孩子 `b`；`a` 的右孩子 `c`，`c` 的左孩子 `d`，`d` 的右孩子 `e`，`e` 的左孩子 `f`（即一条「左右交替」的单链：a—(右)c—(左)d—(右)e—(左)f）。
  5. **求后序**（左 → 右 → 根）：左子树 `b`；右子树内层自底向上得 `f,e,d,c`；最后根 `a`。故 T 的后序遍历 = **`b,f,e,d,c,a`**。
  6. **快速排除**（考场上 10 秒版）：后序**末位必是根** `a` → 排除 A、D；剩下 B、C 的分歧只在 `d` 与 `f,e` 的先后——由 T 的形状知 `e` 是 `d` 的**右孩子**，后序中右子树先于根 `d` 被访问，故 `f,e` 必须先于 `d` 出现 → 选 **C**。

### 2. 三叉哈夫曼树的最小 WPL（全国联考 2013）

- **题目**：已知三叉树 T 中 6 个叶结点的权分别是 2, 3, 4, 5, 6, 7，T 的带权（外部）路径长度最小是（ ）。

  - A. 27
  - B. 46　← **正确答案**
  - C. 54
  - D. 56

- **正确答案**：**B**
- **正解过程**：
  1. m=3，n=6。(n−1) mod (m−1) = 5 mod 2 = 1 ≠ 0 → **补 1 个权为 0 的虚叶**。
  2. 集合 {0,2,3,4,5,6,7}。三次合并：0+2+3=**5**，4+5+5=**14**，6+7+14=**27**。
  3. WPL = 各次新结点权值之和 = 5+14+27 = **46**（虚叶不计入定义式，但已通过把 2、3 压到更深而影响 WPL）。
  4. A.27 是根的权，不是 WPL。
