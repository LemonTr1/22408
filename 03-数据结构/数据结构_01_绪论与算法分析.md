## ❌ 错题

### 1. 程序段的时间复杂度（全国联考 2022 年 · 第 2 题）

- **题目**：下列程序段的时间复杂度是（ ）。

  ```c
  int sum = 0;
  for (int i = 1; i < n; i *= 2)
      for (int j = 0; j < i; j++)
          sum++;
  ```

  - A. O(log₂n)
  - B. O(n)　← **正确答案**
  - C. O(n log₂n)
  - D. O(n²)

- **正确答案**：**O(n)**
- **正解过程**：
  1. 外层 `i = 1, 2, 4, …, 2^k`，满足 `2^k < n`，故执行 **⌈log₂n⌉ 次**；
  2. 内层上限是**变量 i**（不是 n），第 m 次外层内层执行 `i = 2^(m-1)` 次；
  3. 总次数 `T(n) = 1 + 2 + 4 + … + 2^(k) = 2^(k+1) − 1 < 2n − 1`；
  4. 主导项由**最后一次迭代**（≈ n）决定 → **T(n) = O(n)**。
