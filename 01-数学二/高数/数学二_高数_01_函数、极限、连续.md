# 01 函数、极限、连续

> 重点：等价无穷小、洛必达、泰勒展开

## 📐 必背公式

### ① 等价无穷小（$x\to 0$）

> ⚠️ **使用规则：合法替换的判据是「替换后不改变原式的阶」。本质就是泰勒展开取最低阶项。**
>
> - **乘除**：无条件可用 —— 因式替换不影响整体阶数。
> - **加减**：**只要替换后主项不抵消，就照样能用**；只有当低阶项被消掉、替换后结果为 $0$ 时，才必须补高阶项。
>
> | 情形 | 例子 | 能否直接替换 |
> |---|---|---|
> | 加减后主项**不抵消** | $\lim\limits_{x\to 0}\dfrac{\tan x+\sin x}{x}$：替换后 $\dfrac{x+x}{x}=2$，主项 $x$ 仍在 | ✅ 可以 |
> | 加减后主项**抵消** | $\lim\limits_{x\to 0}\dfrac{\tan x-\sin x}{x^{3}}$：替换后 $x-x=0$ | ❌ 不行，须展到三阶得 $\dfrac{1}{2}$ |
>
> **为什么**：$f\sim g$ 的含义是 $f=g+o(g)$ —— 等价无穷小就是泰勒**取一阶**的结论。乘除中高阶项会被约掉，所以无害；加减中一旦低阶项两两抵消，原先被丢弃的 $o(\cdot)$ 就上位成与分母同阶的主角，**必须把丢掉的阶补回来**。所谓「必须用泰勒」，指的就是这种抵消情形。

**一阶组**（与 $x$ 同阶）

| 等价关系                                 | 备注                                      |
| ------------------------------------ | --------------------------------------- |
| $\sin x\sim x$、$\tan x\sim x$        | 最基本两式                                   |
| $\arcsin x\sim x$、$\arctan x\sim x$  | 反三角也是一阶                                 |
| $e^{x}-1\sim x$                      |                                         |
| $\ln(1+x)\sim x$                     |                                         |
| $a^{x}-1\sim x\ln a$                 | $a>0,a\ne 1$；取 $a=e$ 即上式                |
| $\log_{a}(1+x)\sim \dfrac{x}{\ln a}$ |                                         |
| $(1+x)^{\alpha}-1\sim \alpha x$      | 万用式，$\sqrt{1+x}-1\sim\dfrac{x}{2}$ 是其特例 |
| $(1+x)^{1/x}-e\sim -\dfrac{e}{2}x$   | 幂指函数专用                                  |

**二阶组**（与 $x^{2}$ 同阶）

| 等价关系 | 备注 |
|---|---|
| $1-\cos x\sim\dfrac{x^{2}}{2}$ | 「1 减余弦」出平方项 |
| $\sec x-1\sim\dfrac{x^{2}}{2}$ | |
| $x-\ln(1+x)\sim\dfrac{x^{2}}{2}$ | |
| $\ln(1+x)-x\sim-\dfrac{x^{2}}{2}$ | ⚠️ 注意负号 |

**三阶组**（与 $x^{3}$ 同阶）—— 高频陷阱区

| 等价关系 | 备注 |
|---|---|
| $x-\sin x\sim\dfrac{x^{3}}{6}$ | |
| $\arcsin x-x\sim\dfrac{x^{3}}{6}$ | |
| $\tan x-x\sim\dfrac{x^{3}}{3}$ | |
| $x-\arctan x\sim\dfrac{x^{3}}{3}$ | |
| $\tan x-\sin x\sim\dfrac{x^{3}}{2}$ | ⚠️ 差式**主项抵消**，不能替换成 $x$，须展到三阶 |

### ② 泰勒展开（麦克劳林公式，$x\to 0$）

**主力三式**（必须默写）

| 函数 | 展开式 |
|---|---|
| $e^{x}$ | $1+x+\dfrac{x^{2}}{2!}+\dfrac{x^{3}}{3!}+\cdots$ |
| $\sin x$ | $x-\dfrac{x^{3}}{3!}+\dfrac{x^{5}}{5!}-\cdots$ |
| $\ln(1+x)$ | $x-\dfrac{x^{2}}{2}+\dfrac{x^{3}}{3}-\cdots$ |

**扩展式**

| 函数 | 展开式 |
|---|---|
| $\cos x$ | $1-\dfrac{x^{2}}{2!}+\dfrac{x^{4}}{4!}-\cdots$ |
| $\dfrac{1}{1-x}$ | $1+x+x^{2}+x^{3}+\cdots$ |
| $\dfrac{1}{1+x}$ | $1-x+x^{2}-x^{3}+\cdots$ |
| $(1+x)^{\alpha}$ | $1+\alpha x+\dfrac{\alpha(\alpha-1)}{2!}x^{2}+\dfrac{\alpha(\alpha-1)(\alpha-2)}{3!}x^{3}+\cdots$ |
| $\tan x$ | $x+\dfrac{x^{3}}{3}+\dfrac{2x^{5}}{15}+\cdots$ |
| $\arcsin x$ | $x+\dfrac{x^{3}}{6}+\dfrac{3x^{5}}{40}+\cdots$ |
| $\arctan x$ | $x-\dfrac{x^{3}}{3}+\dfrac{x^{5}}{5}-\cdots$ |

**记忆法与用法**

- **只需死记 $e^{x}$、$\sin x$、$\ln(1+x)$ 三式**：$\cos x$ 由 $\sin x$ 逐项求导得；$\dfrac{1}{1\pm x}$ 是等比级数；$(1+x)^{\alpha}$ 是二项式展开。
- **展开到几阶**：原则是「**展到分子分母同阶，或分子出现第一个非零项为止**」。分母若是 $x^{3}$，分子各项至少展到 $x^{3}$。
- 上表三阶组与三阶等价无穷小是**同一件事** —— 等价无穷小即泰勒公式的低阶结论，记一套即可，另一套自然推得出。

### ③ 重要极限与配套结论

- $\lim\limits_{x\to 0}\dfrac{\sin x}{x}=1$；$\lim\limits_{x\to 0}(1+x)^{\frac{1}{x}}=e$；$\lim\limits_{x\to\infty}\Bigl(1+\dfrac{1}{x}\Bigr)^{x}=e$
- $\lim\limits_{x\to 0}\dfrac{a^{x}-1}{x}=\ln a$；$\lim\limits_{x\to 0}\dfrac{\ln(1+x)}{x}=1$；$\lim\limits_{x\to 0}\dfrac{(1+x)^{\alpha}-1}{x}=\alpha$
- **$1^{\infty}$ 型**：结论式 $\lim u^{v}=e^{\lim v(u-1)}$，两法详解见下方「🔢 常见题型 1」
- **极限存在 ⟺ 左右极限存在且相等**（分段函数、$e^{1/x}$、$\arctan\frac{1}{x}$ 型题必查）
- 无穷小 $\times$ 有界 = 无穷小；无穷小与无穷大互为倒数关系

### ④ 和差化积与积化和差

> 两组公式互为**逆运算**（左右对调即可），**必须成对记**。顺带把两角和差公式与辅助角公式一并收进来，凑成完整的三角恒等变换工具箱。

**和差化积**（和差 $\to$ 乘积）

| 公式 | 表达式 |
|---|---|
| $\sin\alpha+\sin\beta$ | $2\sin\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}$ |
| $\sin\alpha-\sin\beta$ | $2\cos\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}$ |
| $\cos\alpha+\cos\beta$ | $2\cos\dfrac{\alpha+\beta}{2}\cos\dfrac{\alpha-\beta}{2}$ |
| $\cos\alpha-\cos\beta$ | $-2\sin\dfrac{\alpha+\beta}{2}\sin\dfrac{\alpha-\beta}{2}$ |

> 💡 **记忆法（从右往左配对）**：
> ① 把 $\alpha,\beta$ 换成 $\frac{\alpha+\beta}{2}$（记为 $A$）与 $\frac{\alpha-\beta}{2}$（记为 $B$），四个式子都变成 $2\times$【某项】。
> ② **同名函数**：$\sin$ 配「**正★余**」（$\sin A\cos B$），$\cos$ 配「**余★余**」（$\cos A\cos B$）。
> ③ **符号看前面**：③ 全是 $+$；①② 的符号**随左边**（$\sin\alpha+\sin\beta$ 取 $+$，$-$ 取 $-$）。
> ④ ⚠️ **$\cos\alpha-\cos\beta$ 是唯一带负号的**，记「余弦相减，前面加负」。

**积化和差**（乘积 $\to$ 和差，上面四式左右对调）

| 公式 | 表达式 |
|---|---|
| $\sin\alpha\cos\beta$ | $\dfrac{1}{2}\bigl[\sin(\alpha+\beta)+\sin(\alpha-\beta)\bigr]$ |
| $\cos\alpha\sin\beta$ | $\dfrac{1}{2}\bigl[\sin(\alpha+\beta)-\sin(\alpha-\beta)\bigr]$ |
| $\cos\alpha\cos\beta$ | $\dfrac{1}{2}\bigl[\cos(\alpha+\beta)+\cos(\alpha-\beta)\bigr]$ |
| $\sin\alpha\sin\beta$ | $-\dfrac{1}{2}\bigl[\cos(\alpha+\beta)-\cos(\alpha-\beta)\bigr]$ |

> 💡 **记忆法**：
> ① 系数恒为 $\dfrac{1}{2}$。
> ② **$\sin\cdot\cos$ 型 → 全化成 $\sin$ 的和差**（正得正、余弦在前取 $-$，见第 2 式），且**$\sin(\alpha+\beta)$ 在前**。
> ③ **$\cos\cdot\cos$ 型 → $\cos$ 相加**；**$\sin\cdot\sin$ 型 → $\cos$ 相减，且整体带负号**。
> ④ 「同名相乘出余弦，异名相乘出正弦」。

**配套：两角和差公式**（是上面两组公式的源头）

| 公式 | 表达式 |
|---|---|
| $\sin(\alpha\pm\beta)$ | $\sin\alpha\cos\beta\pm\cos\alpha\sin\beta$ |
| $\cos(\alpha\pm\beta)$ | $\cos\alpha\cos\beta\mp\sin\alpha\sin\beta$ |
| $\tan(\alpha\pm\beta)$ | $\dfrac{\tan\alpha\pm\tan\beta}{1\mp\tan\alpha\tan\beta}$ |

**配套：辅助角公式**（合一变形，求值域/周期必用）

$$a\sin x+b\cos x=\sqrt{a^{2}+b^{2}}\,\sin(x+\varphi),\qquad \tan\varphi=\frac{b}{a}$$

> 💡 考研常用特例：$\sin x\pm\cos x=\sqrt{2}\sin\bigl(x\pm\frac{\pi}{4}\bigr)$；$\sin x\pm\sqrt{3}\cos x=2\sin\bigl(x\pm\frac{\pi}{3}\bigr)$。

**配套：二倍角与降幂**（积分题高频）

| 公式 | 表达式 |
|---|---|
| $\sin 2x$ | $2\sin x\cos x$ |
| $\cos 2x$ | $\cos^{2}x-\sin^{2}x=2\cos^{2}x-1=1-2\sin^{2}x$ |
| **降幂** $\sin^{2}x$ | $\dfrac{1-\cos 2x}{2}$ |
| **降幂** $\cos^{2}x$ | $\dfrac{1+\cos 2x}{2}$ |

**配套：万能代换**（三角有理式积分，参数化三角）

| 令 $t=\tan\dfrac{x}{2}$ | |
|---|---|
| $\sin x$ | $\dfrac{2t}{1+t^{2}}$ |
| $\cos x$ | $\dfrac{1-t^{2}}{1+t^{2}}$ |
| $dx$ | $\dfrac{2}{1+t^{2}}\,dt$ |

> ⚠️ **考场上直接推的方法**：和差化积忘了就用两角和差公式硬推 —— 令 $A=\frac{\alpha+\beta}{2}$、$B=\frac{\alpha-\beta}{2}$，则 $\alpha=A+B$、$\beta=A-B$，代入 $\sin(A+B)+\sin(A-B)=2\sin A\cos B$ 即得第一式。**其余全部照抄这个套路。**

## 🔢 常见题型

### 1. $1^{\infty}$ 型极限（幂指函数）

**识别**：底数 $\to 1$、指数 $\to\infty$ **同时发生**，形如 $u(x)^{v(x)}$。

**方法一：凑 $(1+x)^{\frac{1}{x}}$ 形式（首选）**

核心是凑第二个重要极限 $\lim\limits_{x\to 0}(1+x)^{\frac{1}{x}}=e$。把底数拆成 $1+\alpha$（$\alpha=u-1\to 0$），再给指数乘除 $\frac{1}{\alpha}$，人为把 $\frac{1}{\alpha}$ 凑出来：

$$\lim u^{v}=\lim\Bigl[(1+\alpha)^{\frac{1}{\alpha}}\Bigr]^{\alpha v}=e^{\lim \alpha v}$$

> 📌 **直接记结论式**（考场最快）：
> $$\lim u^{v}=e^{\lim\, v(u-1)}\qquad(u\to 1,\ v\to\infty)$$

**方法二：取对数**

令 $y=u^{v}$，两边取对数得 $\ln y=v\ln u$，先算出 $\lim \ln y=L$，再利用 $e^{x}$ 的连续性回代：

$$\lim u^{v}=e^{\lim \ln y}=e^{\lim v\ln u}$$

> 💡 **两法是同一件事**：$\ln u=\ln\bigl(1+(u-1)\bigr)\sim u-1$，代回即得到方法一的结论式。**方法一是方法二在 $u\to1$ 时的化简版**，故能凑就直接凑，凑不动（如含 $\ln$ 的复杂底）再取对数。


**例题 **　求 $\lim\limits_{x\to 0^{+}}\bigl(\cos\sqrt{x}\bigr)^{\frac{1}{x}}$

- 判定：底数 $\cos\sqrt{x}\to 1$，指数 $\dfrac{1}{x}\to+\infty$ → **$1^{\infty}$ 型**。
- **方法一（凑）**：
  $$\lim\limits_{x\to 0^{+}}\bigl(\cos\sqrt{x}\bigr)^{\frac{1}{x}}=\lim\limits_{x\to 0^{+}}\Bigl\{\bigl[1+(\cos\sqrt{x}-1)\bigr]^{\frac{1}{\cos\sqrt{x}-1}}\Bigr\}^{\frac{\cos\sqrt{x}-1}{x}}$$
  其中
  $$\lim\limits_{x\to 0^{+}}\frac{\cos\sqrt{x}-1}{x}=\lim\limits_{x\to 0^{+}}\frac{-\frac{1}{2}(\sqrt{x})^{2}}{x}=-\frac{1}{2}$$
  （用二阶组 $1-\cos u\sim\dfrac{u^{2}}{2}$，取 $u=\sqrt{x}$）
  故原式 $=e^{-\frac{1}{2}}$。
- **方法二（取对数）**：
  $$\lim\limits_{x\to 0^{+}}\bigl(\cos\sqrt{x}\bigr)^{\frac{1}{x}}=\lim\limits_{x\to 0^{+}}e^{\frac{\ln\cos\sqrt{x}}{x}}$$
  洛必达法则算指数：
  $$\lim\limits_{x\to 0^{+}}\frac{\ln\cos\sqrt{x}}{x}=\lim\limits_{x\to 0^{+}}\Bigl(\frac{-\sin\sqrt{x}}{\cos\sqrt{x}}\cdot\frac{1}{2\sqrt{x}}\Bigr)=-\frac{1}{2}\lim\limits_{x\to 0^{+}}\frac{\tan\sqrt{x}}{\sqrt{x}}=-\frac{1}{2}$$
  （末步 $\dfrac{\tan\sqrt{x}}{\sqrt{x}}\to 1$，即令 $u=\sqrt{x}\to 0^{+}$）
  故原式 $=e^{-\frac{1}{2}}$。

> ⚠️ **本题为何取 $x\to 0^{+}$**：式中含 $\sqrt{x}$，左极限处函数无定义，**只能求右极限**。见根号先想定义域，这是单侧极限的典型触发点。
> 💡 **秒杀路径**：方法二未必要用洛必达 —— 直接用等价无穷小 $\ln\cos\sqrt{x}\sim\cos\sqrt{x}-1\sim-\dfrac{x}{2}$ 两步到位，与方法一殊途同归。**考场上优先凑 + 等价无穷小，洛必达留给不好凑的场合。**

> ⚠️ **易错**：底数必须**整体**写作 $1+\alpha$。若底数是 $\dfrac{x+2}{x+1}$，则应写成 $1+\dfrac{1}{x+1}$，而不能把分子分母各自替换 —— 理由同 ① 区的「阶不抵消」判据。
