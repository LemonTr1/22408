# 03 一元函数积分学

> 重点：不定积分技巧、定积分性质、反常积分、旋转体体积

## 📐 必背公式

### ① 基本积分表

**幂、指、对**

| 积分 | 结果 |
|---|---|
| $\int x^{\alpha}\,dx$ | $\dfrac{x^{\alpha+1}}{\alpha+1}+C\quad(\alpha\ne -1)$ |
| $\int \dfrac{dx}{x}$ | $\ln\vert x\vert+C$ |
| $\int e^{x}\,dx$ | $e^{x}+C$ |
| $\int a^{x}\,dx$ | $\dfrac{a^{x}}{\ln a}+C$ |
| $\int \ln x\,dx$ | $x\ln x-x+C$ |

**三角基本组**

| 积分 | 结果 |
|---|---|
| $\int \sin x\,dx$ | $-\cos x+C$ |
| $\int \cos x\,dx$ | $\sin x+C$ |
| $\int \sec^{2}x\,dx$ | $\tan x+C$ |
| $\int \csc^{2}x\,dx$ | $-\cot x+C$ |
| $\int \sec x\tan x\,dx$ | $\sec x+C$ |
| $\int \csc x\cot x\,dx$ | $-\csc x+C$ |

**三角「对数型」组**（结果含 $\ln$，最易记混）

| 积分 | 结果 |
|---|---|
| $\int \tan x\,dx$ | $-\ln\vert\cos x\vert+C$ |
| $\int \cot x\,dx$ | $\ln\vert\sin x\vert+C$ |
| $\int \sec x\,dx$ | $\ln\vert\sec x+\tan x\vert+C$ |
| $\int \csc x\,dx$ | $\ln\vert\csc x-\cot x\vert+C$ |

**反三角与根式**（考研最常考的一组）

| 积分 | 结果 |
|---|---|
| $\int \dfrac{dx}{1+x^{2}}$ | $\arctan x+C$ |
| $\int \dfrac{dx}{\sqrt{1-x^{2}}}$ | $\arcsin x+C$ |
| $\int \dfrac{dx}{a^{2}+x^{2}}$ | $\dfrac{1}{a}\arctan\dfrac{x}{a}+C$ |
| $\int \dfrac{dx}{\sqrt{a^{2}-x^{2}}}$ | $\arcsin\dfrac{x}{a}+C$ |
| $\int \dfrac{dx}{x^{2}-a^{2}}$ | $\dfrac{1}{2a}\ln\Bigl\vert\dfrac{x-a}{x+a}\Bigr\vert+C$ |
| $\int \dfrac{dx}{\sqrt{x^{2}\pm a^{2}}}$ | $\ln\Bigl\vert x+\sqrt{x^{2}\pm a^{2}}\Bigr\vert+C$ |
| $\int \sqrt{a^{2}-x^{2}}\,dx$ | $\dfrac{x}{2}\sqrt{a^{2}-x^{2}}+\dfrac{a^{2}}{2}\arcsin\dfrac{x}{a}+C$ |

> 💡 记忆线索：**看到「分母带 $+$ 平方」→ $\arctan$；看到「分母带 $-$ 平方（根号内）」→ $\arcsin$**；两个 $\ln$ 型都带 $\dfrac{1}{2a}$ 或「原式加根号」。

### ② 三大方法

| 方法 | 公式 / 适用场景 |
|---|---|
| 凑微分（第一换元） | $\int f(\varphi(x))\varphi'(x)\,dx=\int f(u)\,du$；见 $f'$ 配 $f$ 就凑 |
| 第二换元 | $\sqrt{a^{2}-x^{2}}\Rightarrow x=a\sin t$；$\sqrt{a^{2}+x^{2}}\Rightarrow x=a\tan t$；$\sqrt{x^{2}-a^{2}}\Rightarrow x=a\sec t$ |
| 分部积分 | $\int u\,dv=uv-\int v\,du$；**$u$ 的选取顺序「反对幂指三」**（反三角 $\to$ 对数 $\to$ 幂 $\to$ 指数 $\to$ 三角），越靠左越当 $u$ |
| 有理函数 | 真分式拆**部分分式**；假分式先做多项式除法 |
| 三角有理式 | **万能代换** $t=\tan\dfrac{x}{2}$：$\sin x=\dfrac{2t}{1+t^{2}}$，$\cos x=\dfrac{1-t^{2}}{1+t^{2}}$，$dx=\dfrac{2}{1+t^{2}}dt$ |

### ③ 定积分常用结论

- **牛顿-莱布尼茨公式**：$\int_a^{b}f(x)\,dx=F(b)-F(a)$
- **偶倍奇零**：$\int_{-a}^{a}f(x)\,dx=2\int_0^{a}f(x)\,dx$（$f$ 为偶），$=0$（$f$ 为奇）
- **区间再现**：$\int_a^{b}f(x)\,dx=\int_a^{b}f(a+b-x)\,dx$（处理 $\int_0^{\pi}\frac{x\sin x}{1+\cos^{2}x}dx$ 这类题的唯一出路）
- **周期函数**：$\int_a^{a+T}f(x)\,dx=\int_0^{T}f(x)\,dx$
- **$\sin$ 的对称**：$\int_0^{\pi}f(\sin x)\,dx=2\int_0^{\pi/2}f(\sin x)\,dx$
- **华里士公式（华莱士 / 点火公式）**：递降 $I_{n}=\dfrac{n-1}{n}I_{n-2}$，口诀「**偶乘 $\frac{\pi}{2}$，奇乘 1**」。展开、混积、区间化归见下方「🔢 常见题型 1」

### ④ 几何应用

- **平面图形面积**：$S=\int_a^{b}\bigl[f(x)-g(x)\bigr]\,dx$（上减下）
- **绕 $x$ 轴旋转体体积**：$V_{x}=\pi\int_a^{b}f^{2}(x)\,dx$
- **绕 $y$ 轴旋转体体积（柱壳法）**：$V_{y}=2\pi\int_a^{b}x\,f(x)\,dx$
- **弧长**：$s=\int_a^{b}\sqrt{1+[f'(x)]^{2}}\,dx$

### ⑤ 反常积分的收敛性（$p$ 积分）

- 无穷区间：$\int_1^{+\infty}\dfrac{dx}{x^{p}}$ **收敛 ⟺ $p>1$**
- 瑕点型：$\int_0^{1}\dfrac{dx}{x^{p}}$ **收敛 ⟺ $p<1$**

> 一句话：**无穷远处要「衰减得够快」（$p>1$），瑕点处要「发散得不够猛」（$p<1$）**。

## 🔢 常见题型

### 1. 华里士公式（华莱士 / 点火公式）

**识别**：积分限是 $\bigl[0,\tfrac{\pi}{2}\bigr]$，被积函数是 $\sin^{n}x$、$\cos^{n}x$ 或 $\sin^{m}x\cos^{n}x$（$n,m$ 为非负整数）。

记 $I_{n}=\displaystyle\int_{0}^{\pi/2}\sin^{n}x\,dx=\int_{0}^{\pi/2}\cos^{n}x\,dx$。对 $\cos$ 做 $t=\frac{\pi}{2}-x$ 即与 $\sin$ 相同，只需记一套。

**递推（一切的源头）**

$$I_{n}=\frac{n-1}{n}\,I_{n-2},\qquad I_{0}=\frac{\pi}{2},\quad I_{1}=1$$

**考场写法：逐项降 2 连乘**（不要现场算双阶乘）

从 $n$ 降到 $1$ 或 $2$，全是分数相乘：

| $n$ | $I_{n}$ |
|---|---|
| 偶数 | $\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{1}{2}\cdot\dfrac{\pi}{2}$ |
| 奇数 | $\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{2}{3}\cdot 1$ |

口诀：**偶乘 $\dfrac{\pi}{2}$，奇乘 $1$。**

例：$\displaystyle\int_{0}^{\pi/2}\sin^{4}x\,dx=\dfrac{3}{4}\cdot\dfrac{1}{2}\cdot\dfrac{\pi}{2}=\dfrac{3\pi}{16}$；$\displaystyle\int_{0}^{\pi/2}\cos^{5}x\,dx=\dfrac{4}{5}\cdot\dfrac{2}{3}=\dfrac{8}{15}$。

**备查（与连乘等价，可用来对答案）**

$$I_{n}=\frac{(n-1)!!}{n!!}\times\begin{cases}\dfrac{\pi}{2}, & n\text{ 为偶数}\\[6pt] 1, & n\text{ 为奇数}\end{cases}$$

**混积** $\displaystyle\int_{0}^{\pi/2}\sin^{m}x\cos^{n}x\,dx$

| 指数 | 做法 |
|---|---|
| $m$、$n$ 中**有一个为奇数**（或两个都奇） | **不要点火**。把奇数次的那个拆出一次，凑微分：$m$ 奇则拆 $\sin x$，$n$ 奇则拆 $\cos x$ |
| $m$、$n$ **都是偶数** | 点火：$\dfrac{(m-1)!!\,(n-1)!!}{(m+n)!!}\cdot\dfrac{\pi}{2}$，或对其中一个用 $\sin^{2}+\cos^{2}=1$ 降次后再连乘 |

例：$\displaystyle\int_{0}^{\pi/2}\sin^{2}x\cos^{2}x\,dx=\dfrac{1!!\cdot 1!!}{4!!}\cdot\dfrac{\pi}{2}=\dfrac{1}{8}\cdot\dfrac{\pi}{2}=\dfrac{\pi}{16}$。

**区间不是 $\bigl[0,\tfrac{\pi}{2}\bigr]$ 时**

先用对称性化过来，再点火。常用两条：

- $\displaystyle\int_{0}^{\pi}\sin^{n}x\,dx=2I_{n}$（$[0,\pi]$ 上 $\sin x\ge 0$）
- $\displaystyle\int_{0}^{\pi}\cos^{n}x\,dx=\begin{cases}2I_{n}, & n\text{ 为偶数}\\ 0, & n\text{ 为奇数}\end{cases}$（奇数次 $\cos$ 在左右半区间反号抵消）

## ⚠️ 易错点

- **点火公式的积分限必须是 $\bigl[0,\tfrac{\pi}{2}\bigr]$**。别的区间先对称化归，不能直接套连乘。
- **一奇一偶（或两奇）的 $\sin^{m}\cos^{n}$ 不要点火**，拆奇数次那一个去凑微分；只有**两偶**才点火。
- 双阶乘易算错。考场用「从 $n$ 逐项降 2 连乘」，最后偶乘 $\dfrac{\pi}{2}$、奇乘 $1$。
