# 02 数据的表示和运算

> 重点：补码、IEEE 754、溢出判断、定点/浮点运算

## ⚠️ 易错点 / 难点

### IEEE 754 浮点数（以 32 位 float 为例）

**位域划分**：1 位符号位 + 8 位阶码 + 23 位尾数，共 32 位。

**阶码怎么算**
- 阶码正常范围是 `01 ~ FE`（十六进制），`00` 与 `FF` 留给【特殊情况】。
- 阶码字段当作**无符号数**，先算出 e（如 `FE` → e = 254），再减偏置值 $2^{7}-1=127$，
  即 **阶码值 = e − 127**。

**尾数怎么算**
- 规格化数有隐藏位：尾数 `0000...000` 补上隐藏位得 `1.0 0000...`。
- 尾数最低位为 1 时对应 $1+2^{-23}$（**不是** $1+2^{-2}$）。

**特殊情况**（由阶码全 0 / 全 1 触发）
1. 阶码全 0 + 尾数全 0 → $\pm 0$（正负由符号位决定）
2. 阶码全 1 + 尾数全 0 → $+\infty$ / $-\infty$
3. 阶码全 1 + 尾数非 0 → **NaN**（全 1 阶码、全 0 尾数已是 ∞，再大的数不存在，只能记为 NaN）
4. 阶码全 0 + 尾数非 0 → **非规格化数**：尾数**不使用隐藏位**，
   且 **阶码值是 −126，而不是 −127**（易错点：全 0 阶码对应 e = 0，若照规格化那样减偏置会得 −127，这是**错**的）

## 🧩 易混对比

| A | B | 区别 |
|---|---|---|
| 单符号位补码 | 双符号位补码（变形补码） | 单符号位**只看结果本身看不出溢出**，必须结合两个操作数的符号才能判；双符号位把符号扩成两位，**只看结果就能判**（两位不一致即溢出） |
| 单符号位溢出判断 | 双符号位溢出判断 | 前者判据在**操作数**上（操作数同号、结果变号）；后者判据在**结果**上（$S_1 \ne S_2$） |

## 🔢 计算方法：IEEE 754 舍入

> 适用场景：**对阶 / 右规**让尾数右移、低位被移出后，把临时尾数还原成标准 23 位。
> 移出的低位**不直接丢**，先保留用于中间计算，最后统一舍入。

### ① 三个辅助位（G / R / S）

在保留的 23 位尾数**之后**，依次多出三位：

| 名称 | 位置 | 含义 |
|---|---|---|
| 保护位 G（guard） | 紧跟 23 位最低有效位之后的第一位 | 初步判断舍入方向 |
| 舍入位 R（round） | 保护位之后 | 与 G、S 共同构成完整舍入信息 |
| 粘滞位 S（sticky） | 舍入位之后 | 舍入位之后被移出的位中**只要有 ≥1 个 1 就置 1**，否则置 0 |

> 💡 G 只代表「半个最低位」的量级；更低位里是否还有 1，全靠 **S 兜住**。

### ② 就近舍入（默认模式）判定三步

规则：取最接近真实值的可表示数；**若恰在正中间，则取尾数最低有效位为偶数的那个**（向偶数舍入）。

1. **G = 0** → 直接舍去。
2. **G = 1 且（R = 1 或 S = 1）** → 尾数加 1（已过半，向上）。
3. **G = 1、R = 0、S = 0** → 恰在正中间：尾数末位为**奇**则加 1（凑成偶数），为**偶**则不加。

> 🔑 口诀：**G 定方向，S 兜底，正中间才看奇偶**。
> IEEE 754 共四种舍入模式，另外三种（朝零 = 截断、朝 $+\infty$、朝 $-\infty$）408 基本不考，重点记就近舍入。

### ③ 套用算例（教材原例，均保留 23 位）

**例 1（非中间值 → 加 1）**

- 临时尾数 $M_1=1.$ `1011 0011 1100 1100 1101 010` `| 101`
- 读三位：G = 1、R = 0、S = 1 → 命中第 ② 条，尾数 **加 1**
- 结果 23 位：`1011 0011 1100 1100 1101 011`

**例 2（正中间且末位为偶 → 不加）**

- 临时尾数 $M_2=1.$ `1011 0011 1100 1100 1101 010` `| 100`
- 读三位：G = 1、R = 0、S = 0 → 恰在正中间，末位 `0` 为**偶** → **不加**
- 结果 23 位：`1011 0011 1100 1100 1101 010`（保持原样）

> ⚠️ **对比要点**：两例的 G、R **完全相同**，只有 **S 不同**（1 vs 0），结论就从「加 1」变成「不加」。
> 这正是粘滞位存在的意义 —— 分辨「正好落在正中间」与「比正中间还略大一点」。

## 🔢 计算方法：补码双符号位（变形补码）与溢出判断

> 适用场景：补码加减运算后判断是否溢出。**双符号位**又称**变形补码**，即把符号位扩成两位。

### ① 双符号位的编码规则

- **左符号位（$S_1$）**：表示结果的正负 —— $S_1 = 0$ 为正，$S_1 = 1$ 为负。
- **右符号位（$S_2$）**：与左符号位**理应相同**，起**冗余校验**作用。

即：正数记作 `00 + 数值位`，负数记作 `11 + 数值位`（负数的两位符号位由原先的 1 位符号位**直接复制**得来，数值位补码形式不变）。

### ② 溢出判断规则

| 双符号位 $S_1 S_2$ | 含义 |
|---|---|
| `00` | 结果为正，**无溢出** |
| `11` | 结果为负，**无溢出** |
| **`01`** | 正溢出（上溢）：结果本应 > 最大值，左符号判为「正」 |
| **`10`** | 负溢出（下溢）：结果本应 < 最小值，左符号判为「负」 |

> 🔑 口诀：**左符号定正负，右符号异于左符号即溢出**（$S_1 \ne S_2$）。溢出时**左符号位才是真正的符号**，右符号位被运算「污染」。

### ③ 套用算例

设 **n = 5 位**：2 位符号位 + 3 位数值位，真值范围 **−8 ~ +7**。
书写时**前两位为符号位**（下称 $S_1S_2$），后三位为数值位；加法按普通二进制竖式进行，**最高位的进位直接丢弃**。

**例 1（无溢出）**：$-3 + (-2) = -5$

- $-3 \Rightarrow 11101$，$-2 \Rightarrow 11110$
- $11101 + 11110 = (1)\,11011$，丢弃最高进位 → $\mathbf{11011}$
- $S_1S_2 = 11$：两位相同 → **无溢出**，结果 $11011_补 = -5$ ✅

**例 2（正溢出 · 上溢）**：$+5 + (+4) = +9 > +7$

- $+5 \Rightarrow 00101$，$+4 \Rightarrow 00100$
- $00101 + 00100 = \mathbf{01001}$
- $S_1S_2 = 01$：右符号位 ≠ 左符号位 → **正溢出**
  （左符号 0 判为「正」，说明真值本应为正数 $+9$，已超出 +7）

**例 3（负溢出 · 下溢）**：$-5 + (-4) = -9 < -8$

- $-5 \Rightarrow 11011$，$-4 \Rightarrow 11100$
- $11011 + 11100 = (1)\,10111$，丢弃最高进位 → $\mathbf{10111}$
- $S_1S_2 = 10$：右符号位 ≠ 左符号位 → **负溢出**
  （左符号 1 判为「负」，说明真值本应为负数 $-9$，已超出 −8）

### ④ 与单符号位判断的联系

单符号位补码通常用「**操作数同号、结果异号**」判溢出；双符号位把这一判断**提前到了结果本身**：结果两位符号不一致，就说明正确结果已超出表示范围。

## 🔢 计算方法：无符号数乘法 / 除法运算电路

> 出处：王道 2027《计算机组成原理考研复习指导》P40（图 2.10）、P42–43（图 2.12）。

### 一、无符号数乘法运算电路

**图 2.10　一个 32 位无符号数乘法运算器的逻辑结构**

> 组成：被乘数寄存器 X（32 位）→ 32 位 ALU ↑32 ↓32 → 乘积寄存器 P（存高 32 位结果），与乘数寄存器 Y 共 64 位；进位触发器 C；控制逻辑 + 计数器 $C_n$；时钟。

下面介绍其主要组成部分及其工作原理。

**1）初始化**

- **被乘数寄存器 X**：存储 32 位被乘数 X，在整个乘法过程中保持不变。
- **乘数寄存器 Y**：初始时存储 32 位乘数 Y。
- **乘积寄存器 P**：初始化为 0，用于存放累加的部分积（高 32 位结果）。
- **计数器 $C_n$**：初始化为 $n$（本例为 32），表示需进行 $n$ 次迭代。

**2）执行过程（循环 $n$ 次）**

① **判断**：将乘数寄存器 Y 的最低位，送入控制逻辑。

② **加法操作**：若 Y 的最低位为 1，则将当前部分积 P 加上被乘数 X，并将进位存入进位触发器 C；若 Y 的最低位为 0，则执行空操作。

③ **移位操作**：将 C、P 和 Y 视为一个整体，执行一次逻辑右移。具体来说，进位 C 移入 P 的最高位，P 的最低位移入 Y 的最高位，Y 的最低位被丢弃。

④ **更新计数器**：计数器 $C_n$ 减 1。若 $C_n \neq 0$，则继续下一轮迭代，否则算法结束。

**3）最终结果**：64 位积由 **P（高 32 位）与 Y（低 32 位）拼接**而成。

**考点链接 · 无符号数乘法指令的溢出判断（2019、2020）**：迭代结束后高 $n$ 位（即 P）不全为 0 即为溢出 —— 等价于最后一轮加法产生了进位 C = 1。

### 二、无符号整数的除法运算电路

**考点链接 · 除法运算器的结构（2025）**

被除数需高位补 0 扩展为 $2n$ 位，以支持统一的迭代过程。图 2.12 所示为一个 32 位除法逻辑结构图。为了适应逐位试商的迭代过程，需要将被除数加载到一个 64 位寄存器中（高 32 位为 0，低 32 位为实际被除数）。一般而言，$n$ 位无符号数除法采用一个 $2n$ 位的被除数（高位补 0）除以一个 $n$ 位的除数，产生 $n$ 位的商和 $n$ 位的余数。

**图 2.12　一个 32 位除法逻辑结构图**

> 组成：除数寄存器 Y（32 位）→ 32 位 ALU（加/减）↑32 ↓32 → 余数寄存器 R，与余数/商寄存器 Q 共 64 位；控制逻辑 + 计数器 $C_n$；时钟。

**1）初始化**

- **除数寄存器 Y**：存储 $n$ 位除数，在整个除法过程中保持不变。
- **余数/商寄存器 Q**：初始时存储 $n$ 位被除数；在迭代过程中逐步生成 $n$ 位商。
- **余数寄存器 R**：初始化为 0，用于暂存中间余数。
- **计数器 $C_n$**：初始化为 $n$，表示需要执行 $n$ 轮迭代。
- **异常预检**：若除数为 0，则立即触发「除零错误」异常，停止除法运算；若被除数 < 除数，则商 = 0，余数 = 被除数，无须进入执行过程。

## ❌ 错题

### 1. 浮点数加法的双符号位判溢出（2009 全国统考 408 · 第 13 题） 

- **题目**：浮点数加、减运算过程一般包括对阶、尾数运算、规格化、舍入和判溢出等步骤。设浮点数的阶码和尾数均采用补码表示，且位数分别为 5 位和 7 位（均含 2 位符号位）。若有两个数 $X=2^7\times\dfrac{29}{32}$，$Y=2^5\times\dfrac{5}{8}$，则用浮点加法计算 $X+Y$ 的最终结果是（　）。
  - A. `00111 1100010`
  - B. `00111 0100010`
  - C. `01000 0010001`
  - D. 发生溢出　← **正确答案**

- **正确答案**：**D. 发生溢出**
- **正解过程**：
  1. **写出 $X$、$Y$ 的机器表示**（阶码 5 位 = 2 符号位 + 3 数值位，尾数 7 位 = 2 符号位 + 5 数值位，均补码）：
     - $X$：$\dfrac{29}{32}=0.11101_2$（正好 5 位），阶码 $7=\underline{00,111}_{补}$ → $X=\underline{00,111}\,;\,\underline{00,11101}$
     - $Y$：$\dfrac{5}{8}=0.101_2=0.10100_2$（右补 0 凑 5 位），阶码 $5=\underline{00,101}_{补}$ → $Y=\underline{00,101}\,;\,\underline{00,10100}$
  2. **对阶**：$\underline{00,111}-\underline{00,101}=\underline{00,010}$，阶差 **2**。按「**小阶向大阶看齐**」，把 **$Y$ 的尾数右移 2 位**（正数右移高位补 0）：
     - $Y=\underline{00,111}\,;\,\underline{00,00101}$（原 `00,10100` 右移 2 位，低 2 位 `00` 移出）
  3. **尾数相加**（阶码已对齐，双符号位参与运算）：
     ```
         00,11101      (X 的尾数)
       + 00,00101      (Y 对阶后的尾数)
       -----------------
         01,00010
     ```
     结果**两符号位不一致（`01`）**→ 尾数绝对值 ≥ 1，**尾数溢出，需右规**（这正是双符号位的作用：一眼看出要右规）。
  4. **规格化（右规）**：尾数**右移 1 位**、高位补符号位，同时**阶码 +1**：
     - 尾数 `01,00010` → `00,10001`
     - 阶码 $7+1=8$ → 此时 $X+Y=\underline{01,000}\,;\,\underline{00,10001}$
     - ⚠️ 阶码自身的双符号位也变成了 **`01`** —— 这是阶码溢出的信号。
  5. **判溢出（本题胜负手）**：阶码 5 位含 2 个符号位 → 数值位只有 **3 位**，补码表示范围 $-2^3\sim 2^3-1$，即 $-8\sim \mathbf{+7}$。算得阶码真值 **8 > 7**，**阶码上溢**，该浮点格式无法表示 → 选 **D**。
  6. **验算（整数速算法）**：$X+Y=\dfrac{29}{32}\times2^7+\dfrac{5}{8}\times2^5=\dfrac{29}{32}\times2^7+\dfrac{5}{32}\times2^7=\dfrac{34}{32}\times2^7=\dfrac{17}{32}\times2^{\mathbf{8}}$，**阶码为 8**，与第 5 步一致，必然溢出。

- **易错点（三个干扰项怎么来的）**：
  | 选项 | 它等于哪一步的结果 | 错在哪 |
  |---|---|---|
  | B `00111 0100010` | 只做「对阶 + 尾数相加」，**忘记右规** | 阶码仍是 `00111`(7)，尾数 `01,00010` 未规格化 |
  | C `01000 0010001` | 做完了「对阶 + 尾数相加 + 右规」 | **漏做最后一步「判溢出」**——结果本身没算错，但不是最终结果 |
  | D 发生溢出 | 完整五步 | ✔ 阶码 8 超出 3 位数值位的最大 7 |

  > 记忆口径：**双符号位 = `01/10` 只说明「尾数（或阶码）越界」**。对**尾数**而言 `01/10` 是「**该右规了**」；对**阶码**而言 `01/10` 才是「**溢出**」。**右规后阶码 +1，必须回头看一次阶码自己的双符号位**——很多人算完右规就选 C 交卷，就死在这一步。

  > 📌 本题一题吃掉本页两个知识点：**双符号位（变形补码）——用 `01/10` 判断尾数需右规**；**阶码补码的表示范围——3 位数值位最大只能表示 +7**。舍入这一步本题未涉及（对阶时移出的 `00` 正好是 0，右规移出的是 0）。

### 2. IEEE754 单精度的「溢出边界」与「精度边界」（2020 真题改编）

- **题目**（题干手写）：
  ```c
  float f(unsigned n)
  {   float sum=1, power=1;
      for (unsigned i=0; i<=n-1; i++)
      {   power *= 2;
          sum += power;
      }
      return sum;
  }
  ```
  （1）若使 $f(n)$ 的结果**不溢出**，则最大的 $n$ 是多少？
  （2）若使 $f(n)$ 的结果**精确无舍入**，则最大的 $n$ 是多少？

- **正确答案**：**(1) $n_{\max}=126$** ； **(2) $n_{\max}=23$**

- **正解过程**：

  **① 先把函数结果化成一个显式公式**：循环体执行 $n$ 次，`power` 依次取 $2,2^2,\dots,2^n$，累加到初值 1 上：
  $$f(n)=1+2+2^2+\cdots+2^n=2^{n+1}-1$$
  即 $f(n)$ 在二进制下是 **$\underbrace{11\cdots1}_{n+1\ 个}$** —— 这**同时暴露了它的两个性质**：需要 **$n+1$ 个有效位**才能写全，且**数值上略小于 $2^{n+1}$**。

  **② 第 (1) 问：不溢出的边界（看「阶码」）**

  IEEE754 单精度格式：**1 位符号 + 8 位阶码 + 23 位尾数**。阶码用**移码**存放，真值范围 $E\in[-126,127]$，其中**正值最大为 127**（$254-127=127$）。
  - 单精度**最大规格化正数**：
    $$\text{MAX}=1.\underbrace{11\cdots1}_{23}\times 2^{127}=(2-2^{-23})\times 2^{127}=2^{128}-2^{104}$$
  - 卡边界：任何**真值 $\ge 2^{128}$** 的数都**必然上溢**。
  - $f(n)=2^{n+1}-1$，**小于但几乎等于 $2^{n+1}$**。因此：
    $$f(n)<2^{128}\iff n+1\le127\iff \boxed{n\le126}$$
  - 验算（$n=126$）：$f(126)=2^{127}-1$，其阶码为 127（$=E_{\max}$），**仍然不溢出**。
  - 验算（$n=127$）：$f(127)=2^{128}-1>2^{128}-2^{104}=\text{MAX}$ → **上溢**（实际计算结果为 $+\infty$）。

  > ⚠️ 易错陷阱：**判溢出只看阶码，与尾数是否精确无关**——这就是第 (1) 问与第 (2) 问答案相差 103 的根本原因。

  **③ 第 (2) 问：精确无舍入的边界（看「尾数」）**

  单精度尾数**有效位 = 1 个隐藏位（整数位）+ 23 个显式位 = 24 位**。可**精确表示**的最大连续整数为 $2^{24}-1$（即 $24$ 位全 $1$）。
  - $f(n)=2^{n+1}-1=\underbrace{11\cdots1}_{n+1\ 个}$，**要求 $n+1\le24$ 才能被 24 位尾数无损装下**：
    $$\boxed{n\le23}$$
  - 验算（$n=23$）：$f(23)=2^{24}-1=\underbrace{11\cdots1}_{24}$，恰好**填满** 24 位尾数，**刚好容得下，无舍入**。
  - 验算（$n=24$）：$f(24)=2^{25}-1$ 需要 **25 位有效位**，超出 24 位 → **必须舍入**。
  - 舍入细节（为什么恰好差 1？）：对阶到 $E=24$ 后，$2^{25}-1$ 写作 $2^{25}-2^{0}=2^{24}\times(2-2^{-24})$，尾数最多保留到 $2^{-23}$ 位，多出的 $2^{-24}$ 触发**就近舍入**；$2-2^{-24}$ 到两侧等距，进入 **tie-to-even** → 取尾数末位为 0（偶）的一侧 → 结果被舍成 $2^{25}$，**与真值 $2^{25}-1$ 恰好差 1**。

  **④ 一句话对照总结**

  | 问题 | 约束对象 | 关键数字 | 最大 $n$ |
  |---|---|---|---|
  | 不溢出 | **阶码**（范围） | 阶码 8 位含 1 符号位 → $E_{\max}=127$ | **126** |
  | 精确无舍入 | **尾数**（精度） | 尾数 1 隐藏 + 23 显式 = 24 位有效 | **23** |

  > 记忆口径：**「不溢出看阶码 127，不丢精度看尾数 24」**。范围问题找阶码，精度问题找尾数，两者绝不可混用。

  > 📌 关联本页知识点：**IEEE754 单精度格式（1+8+23）**、**阶码移码与真值 $E_{\max}=127$**、**最大规格化数 $2^{128}-2^{104}$**、**尾数有效位 24（含隐藏位）**、**就近舍入 + tie-to-even**。程序附注：`power *= 2` 按 `float` 运算（写整数会提前溢出）；`i<=n-1` 在 $n=0$ 时因无符号减法回绕成 `UINT_MAX` 会死循环，属另一话题。
