# 01 计算机系统概述

> 重点：冯·诺依曼结构、性能指标

## ⚠️ 易错点 / 难点

- **冯·诺依曼计算机体系结构的核心思想 = 存储程序控制**（存储程序 + 程序控制）：程序与数据**一同以二进制形式存入存储器**，机器**自动按地址顺序取指令、译码、执行**，无需人工干预。判别时认准「**存储程序 / 程序控制**」四字。
- 冯·诺依曼计算机的**其他特征**（易被误当成「核心思想」）：① 采用**二进制**表示数据与指令；② 由**五大部件**（运算器、控制器、存储器、输入设备、输出设备）组成；③ 指令由**操作码 + 地址码**构成；④ 指令与数据**同等地位**存放在同一存储器中，按地址访问。**「二进制运算」「五大部件构成」「运算速度快」都不是核心思想**，是核心思想带来的结果或表现形式。
- **机器字长 = CPU 内部用于整数运算的数据通路宽度**（数据通路上各部件宽度须一致才匹配）。因此**一定**与机器字长相同的部件只有：**整数 ALU 的位数**、**通用寄存器的宽度**。
- **指令寄存器（IR）**的位数取决于**指令字长**，不是机器字长：定长指令系统下 IR = 指令字长（可 ≠ 机器字长）；**变长指令系统**下 IR 至少要能存下**最长的那条指令**。
- **浮点寄存器**的位数取决于**浮点数的格式**（如 IEEE 754 的 float 32 位 / double 64 位），与整数数据通路宽度无关，可 ≠ 机器字长。
- **「符号化语言」只指汇编语言，高级语言不是符号化语言**：机器语言是 **0/1 代码串**（二进制代码，**非符号化**）；汇编语言用**助记符**代替操作码、用**符号**代替地址，所以是**符号化语言**；高级语言**面向问题**、接近自然语言与数学表达（如 `a = b + c`），**不属于符号化语言**。⇒ 「机器语言是 0/1 串，高级语言和汇编语言是符号化语言」这种把**高级语言也归为符号化语言**的说法是**错的**。
- **只有机器语言能被硬件直接执行**，汇编语言与高级语言都**不能**：汇编语言虽与机器指令**一一对应**，但仍必须经**汇编程序（assembler）翻译**成机器语言才能执行，**不是「不需要编译就可执行」**。⇒ 「机器语言和汇编语言都能被硬件直接执行」是**错的**；「汇编语言与机器指令一一对应所以不用编译就能执行」也是**错的**。

## ❌ 错题

### 1. 哪些部件的位数一定与机器字长相同（全国联考 2020 年）

- **题目**：下列给出的部件中，其位数（宽度）一定与机器字长相同的是（　）。
  - Ⅰ. ALU
  - Ⅱ. 指令寄存器
  - Ⅲ. 通用寄存器
  - Ⅳ. 浮点寄存器
  - A. 仅Ⅰ、Ⅱ
  - B. 仅Ⅰ、Ⅲ　← **正确答案**
  - C. 仅Ⅱ、Ⅲ
  - D. 仅Ⅱ、Ⅲ、Ⅳ

- **正确答案**：**B. 仅Ⅰ、Ⅲ**

- **正解过程**：
  1. **机器字长的定义**：机器字长指 CPU 内部**用于整数运算**的数据通路宽度（即一次能并行处理的二进制位数）。数据通路上各部件要互相传送数据，宽度必须一致才能匹配，故机器字长 = **整数 ALU 的位数** = **通用寄存器的宽度**。→ Ⅰ、Ⅲ **一定**相等 ✔
  2. **排除 Ⅱ 指令寄存器**：IR 用来存放当前正在执行的指令，其宽度由**指令字长**决定，与机器字长无关。定长指令系统下 IR = 指令字长；**变长指令系统**下 IR 需能容纳**最长的指令**。指令字长本来就可以 ≠ 机器字长，故 Ⅱ **不一定**相等 ✘
  3. **排除 Ⅳ 浮点寄存器**：浮点寄存器存放浮点数，宽度由**浮点数格式**决定（单精度 32 位、双精度 64 位……），只需满足浮点运算要求，无需与整数数据通路等宽，故 Ⅳ **不一定**相等 ✘
  4. 综上，一定与机器字长相同的是 Ⅰ 和 Ⅲ，选 **B**。

> 陷阱提醒：**「机器字长 = 指令字长 = 存储字长」是经典混淆**——题目说「三者相等」时是**题设给的特定条件**，并非普适规律。浮点寄存器/浮点 ALU 属**浮点数据通路**，其宽度由浮点格式决定，是本题最像正确的干扰项。

### 2. 冯·诺依曼计算机体系结构的核心思想

- **题目**：冯·诺依曼计算机体系结构的核心思想是（　）。
  - A. 二进制运算
  - B. 五大部件构成
  - C. 运算速度快
  - D. 存储程序控制　← **正确答案**

- **正确答案**：**D. 存储程序控制**

- **正解过程**：
  1. **核心思想 = 存储程序控制**：程序（指令序列）与数据以**二进制**形式**一并存入存储器**，机器启动后**自动、连续地按地址顺序取出指令并执行**，全程无需人工干预（即程序控制）。
  2. **排除 A「二进制运算」**：冯·诺依曼机**确实**采用二进制，但二进制只是**数据/指令的表示形式**，是核心思想得以实现的前提条件，不是「思想」本身。
  3. **排除 B「五大部件构成」**：运算器、控制器、存储器、输入设备、输出设备是冯·诺依曼机的**结构组成**，属「五大部件」这一**特征**，不是核心思想。
  4. **排除 C「运算速度快」**：速度是**性能指标**，任何计算机都追求，与体系结构思想无关。
  5. 故选 **D**。

> 陷阱提醒：这类题四个选项**本身都是冯·诺依曼机的正确描述**，考的是「**哪一条才是核心**」。答题口诀——**认准「存储程序 / 程序控制」**。冯·诺依曼机的完整特征可记作：**二进制表示 + 五大部件 + 存储程序控制（核心）+ 指令由操作码和地址码组成 + 指令和数据同等地位存于同一存储器、按地址访问**。

### 3. 有关计算机语言的说法中错误的项（杭州电子科技大学 2012 年）

- **题目**：下面有关计算机语言的说法中，错误的是（　）。
  - Ⅰ. 机器语言是由 0/1 代码串构成的代码语言，而高级语言和汇编语言是符号化的语言
  - Ⅱ. 机器语言和汇编语言是面向机器的语言，因此，能够被计算机硬件直接执行
  - Ⅲ. 高级语言需要编译成二进制机器指令后才能执行，而汇编语言因为与机器指令一一对应，所以不需要编译就可执行
  - A. 仅Ⅰ和Ⅱ
  - B. 仅Ⅱ和Ⅲ
  - C. 仅Ⅰ和Ⅲ
  - D. Ⅰ、Ⅱ、Ⅲ　← **正确答案**

- **正确答案**：**D. Ⅰ、Ⅱ、Ⅲ**（三项说法**全部错误**）

- **正解过程**：
  1. **判 Ⅰ 错**：机器语言确实是**由 0/1 代码串构成的二进制代码语言**（这一点对了），但**「符号化语言」专指汇编语言**——汇编用**助记符**代替二进制操作码、用**符号地址**代替数字地址。**高级语言不是符号化语言**，它**面向问题**、接近自然语言和数学表达（如 `a = b + c`），不从属于「符号化语言」这一分类。故 Ⅰ 中把**高级语言也列为符号化语言**是错误的。✘
  2. **判 Ⅱ 错**：机器语言**能**被硬件直接执行 ✔，但**汇编语言不能**——汇编源程序必须经**汇编程序**翻译成机器指令才能运行。Ⅲ（原文 Ⅱ）把「**汇编语言也**能被硬件直接执行」当成结论，错误。✘
  3. **判 Ⅲ 错**：「汇编语言与机器指令**一一对应**」这句本身是对的（助记符形式 ↔ 二进制指令一一对应），但**「一一对应」不等于「不需要翻译」**——汇编语言只是**面向机器**的**低级语言**，仍属**符号化**的源语言，必须由**汇编程序翻译**为机器语言后才可执行。「不需要编译就可执行」错误。✘
  4. 三项均错，故选 **D**。

> 陷阱提醒：本题的陷阱是**「半对半错」**——每项都含一句正确表述，再用 **「因此 / 所以」** 接出一个错误结论。判断时只认最终结论：① **能直接执行硬件的只有机器语言**；② **符号化语言 = 汇编语言，高级语言不属此类**；③ **汇编语言仍需翻译（汇编程序），只是"一一对应"**。
